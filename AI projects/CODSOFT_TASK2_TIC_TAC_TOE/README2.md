**# Tic-Tac-Toe AI**



\## Project Overview



This project is an AI-based Tic-Tac-Toe game developed as part of the CODSOFT Artificial Intelligence Internship.



The player competes against an AI opponent. The AI uses the Minimax algorithm to analyze possible moves and select the best move.



\## Objective



The objective of this project is to understand:



\- Artificial Intelligence decision-making

\- Game theory

\- Minimax algorithm

\- Recursion

\- Search algorithms

\- Python programming



\## Technologies Used



\- Python

\- Minimax Algorithm

\- Recursion

\- Math module



\## Features



\- Human vs AI gameplay

\- Human player uses X

\- AI player uses O

\- AI uses Minimax algorithm

\- Detects winning combinations

\- Detects draws

\- Prevents invalid moves

\- Handles invalid input



\## AI Algorithm



The AI uses the Minimax algorithm.



Minimax evaluates possible future game states and selects the move that provides the best possible outcome for the AI.
