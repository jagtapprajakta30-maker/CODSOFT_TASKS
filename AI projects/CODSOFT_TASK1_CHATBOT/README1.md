**Rule-Based AI Chatbot**

📌 Project Overview



This project is a simple rule-based chatbot developed as part of the CODSOFT Artificial Intelligence Internship.



The chatbot interacts with users through the command line and provides predefined responses based on keywords and patterns found in the user's input.



🎯 Objective



The main objective of this project is to understand the basic concepts of:



Natural Language Processing (NLP)

Pattern matching

Rule-based systems

Conversational flow

Python programming



🛠️ Technologies Used

Python

Conditional statements

String processing

datetime module

⚙️ Features

Responds to greetings

Provides information about itself

Answers basic AI questions

Explains Python and programming

Displays the current date and time

Provides a help command

Handles unknown questions

Allows the user to exit the conversation

▶️ How to Run

Install Python on your computer.

Download or clone this repository.

Open the project folder in VS Code or a terminal.

Run:

python chatbot.py

Start chatting with the chatbot.

💬 Example

You: Hello

Bot: Hello! 👋 How can I help you?





You: What is AI?

Bot: Artificial Intelligence is the ability of machines to perform tasks that normally require human intelligence.





You: What is Python?

Bot: Python is a popular programming language used in AI, machine learning, web development, and data science.





You: Bye

Bot: Goodbye! 👋 Have a great day!

📚 Learning Outcome



Through this project, I learned how rule-based chatbots work, how user input can be processed using string matching, and how predefined rules can control a basic conversational system.
